# R12 ASR M0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the M0 preparation and smoke tooling needed to train a Dataset-A-train-only Paraformer branch without exposing labels in public artifacts or contaminating downstream Router/Gate training.

**Architecture:** Four focused modules own distinct contracts: a private ASR manifest builder, an immutable parent-group fold manifest, a private domain-hotword builder with public digest-only provenance, and a FunASR configuration/checkpoint smoke probe. Thin CLIs call these modules. No command in this plan trains a neural model, reads legacy validation/internal-test labels, or changes the existing R12 evaluation pipeline.

**Tech Stack:** Python 3.11, JSON/JSONL, `unicodedata`, `hashlib`, existing Dataset-A lineage/split helpers, FunASR 1.4.1 (runtime smoke only), pytest.

## Global Constraints

- Work only in `F:\XH-202615\XH-202615\.worktrees\r12-dataa-augmented-internal` on `codex/r12-dataa-augmented-internal`.
- Inputs may include only the immutable augmented split, derived lineage, and private **train-parent** labels. Validation and internal-test label paths are not accepted by M0 APIs or CLIs.
- ASR supervision includes only train-role rows whose parent label is a nonempty string; each `original`/`aug_a`/`aug_b` child inherits its parent text.
- Negative samples must never appear in ASR training/validation manifests, but they remain in the fold manifest so later OOF inference can cover them.
- Target text is NFKC-normalized, stripped of FunASR rich tags, and required to be nonempty. Private target text may be written only below an explicitly named `private/` directory.
- Public manifests/summaries must contain no target/reference/label text or hotword strings; store only IDs, counts, deterministic configuration, and SHA-256 digests.
- All writes fail if the exact output target already exists. No existing run artifacts, raw Dataset-A audio, split manifest, or old internal test are overwritten/read for scoring.
- Parent group is the splitting unit. Every augmentation child has the same outer fold as its parent. Default seed is exactly `20260814`; default fold count is exactly `3`.
- An ASR fold record represents every train-role lineage row (positive and negative); downstream code must be able to reject an `in_sample` candidate explicitly.
- FunASR smoke has `config` and `load` levels only. It does not call `generate`, run a backward pass, create checkpoints, or allocate CUDA by default. CUDA memory probing is a future explicit action after GPU is free.

```python
@dataclass(frozen=True)
class SmokeConfig:
    model: str
    mode: Literal["lora", "freeze_encoder"]
    device: str
    level: Literal["config", "load"]
    lora_list: tuple[str, ...] = ("q", "k", "v", "o")
@dataclass(frozen=True)
class SmokeResult:
    config: SmokeConfig
    loaded: bool
    total_parameter_count: int
    trainable_parameter_names: tuple[str, ...]
    lora_parameter_count: int

def build_loader_kwargs(config: SmokeConfig) -> dict[str, object]:
    """Return only ASR model arguments; never add VAD, punctuation, or a dataset path."""

def run_smoke(config: SmokeConfig, *, loader: Callable[..., object] | None = None) -> SmokeResult:
    """Validate configuration or load one ASR model without decoding, training, or checkpoint writes."""
```

For `lora`, construct `AutoModel` kwargs with only `model`, `device`, `disable_update=True`, `encoder_conf`, `decoder_conf`, and `lora_only=True`; pass `lora_list`/rank/alpha/dropout only when explicitly supplied by the CLI. For `freeze_encoder`, load the plain ASR model and set `requires_grad=False` only for parameter names beginning `encoder.`. Do not instantiate VAD, punctuation, or call `generate`. The injected fake loader returns an object exposing `.model.named_parameters()`; the real default loader imports `funasr.AutoModel` only at load time.
